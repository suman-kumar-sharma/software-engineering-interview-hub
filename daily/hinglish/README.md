# Daily Interview Preparation — Hinglish

This folder stores **Hinglish companion reports** for daily English interview preparation.

## Expected structure
```text
daily/
├── YYYY/MM/Interview_Preparation_YYYY-MM-DD.md           # English
└── hinglish/YYYY/MM/Interview_Preparation_YYYY-MM-DD.md  # Hinglish
```

## Explanation style
- Concepts, intuition, dry runs, and trade-offs in natural Roman-script Hindi + English.
- Java code, algorithms, class names, and technical terms remain in English.
- Include **how the solution was derived**, not only final answers.
- For HLD and LLD, walk through clarification, design, implementation, failure cases, trade-offs, and a professional English sample answer.
- Maintain at least **80% product-company SDE2/Senior focus**.
- Preserve original source URLs and distinguish verified facts from reported interview experiences.

> The GitHub Actions workflow requires `OPENAI_API_KEY` and a successful run before new companion reports appear. Historical English reports are not automatically backfilled.
